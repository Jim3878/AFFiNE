# 公式欄位語法說明

資料庫的 **Formula** 欄位用公式算出每一列的值，語法跟 Notion 的公式相同（常用的部分）。
公式的結果每次顯示時重新計算，不會存進資料裡；改了其他欄位，公式會跟著更新。

## 編輯公式

1. 新增欄位，類型選 **Formula**。
2. 點欄位標題，選 **Edit formula**；或點公式欄位的任一格，按 **Enter**（或再點一次）。
3. 輸入公式。編輯框下方會即時顯示結果（從格子打開時是那一列，從標題打開時是第一列），寫錯時顯示錯誤原因。
4. **Enter** 存檔，**Shift+Enter** 換行，**Esc** 取消。

一個欄位只有一條公式，在哪一格編輯都一樣，整欄都會套用。

## 讀取欄位：`prop("名稱")`

`prop("欄位名稱")` 讀取同一列某個欄位的值。名稱要加引號，跟欄位標題一樣（不分大小寫）。
編輯框下方「Properties」列出所有欄位，點一下就會插入 `prop("…")`。

| 欄位類型         | 讀到的值                                           |
| ---------------- | -------------------------------------------------- |
| 數字、進度       | 數字（空白時算作 0）                               |
| 勾選             | `true` / `false`                                   |
| 單選             | 選項文字，例如 `"進行中"`                          |
| 多選             | 選項文字的清單                                     |
| 日期、建立時間   | 日期                                               |
| 文字、連結、標題 | 文字（標題欄位沒有自己的名稱時用 `prop("Title")`） |
| 關聯             | 關聯到的列的清單（見下面「關聯欄位」）             |
| 其他公式         | 那個公式的結果                                     |

## 基本寫法

| 寫法                                 | 說明                                              |
| ------------------------------------ | ------------------------------------------------- |
| `123`、`1.5`                         | 數字                                              |
| `"文字"`                             | 文字，雙引號或單引號都可以，全形引號 `“ ”` 也可以 |
| `true`、`false`                      | 是／否                                            |
| `[1, 2, 3]`                          | 清單                                              |
| `+ - * / %`                          | 加減乘除、餘數                                    |
| `^`                                  | 次方，`2 ^ 3` = 8                                 |
| `+`（文字）                          | 文字相加會接起來，`"A" + "B"` = `"AB"`            |
| `== != > >= < <=`                    | 比較，結果是 true / false                         |
| `and`、`or`、`not`（或 `&& \|\| !`） | 且、或、非                                        |
| `條件 ? 甲 : 乙`                     | 條件成立取甲，否則取乙                            |
| `( )`                                | 改變運算順序                                      |

函式可以用兩種寫法，意思一樣：`round(prop("價格"))` 或 `prop("價格").round()`。
第二種寫法適合連續處理：`prop("裝備").map(current.prop("價格")).sum()`。

## 條件判斷

| 函式                                   | 說明                                | 例子                                                         |
| -------------------------------------- | ----------------------------------- | ------------------------------------------------------------ |
| `if(條件, 甲, 乙)`                     | 條件成立取甲，否則取乙              | `if(prop("完成"), "✅", "⏳")`                               |
| `ifs(條件1, 值1, 條件2, 值2, …, 其他)` | 依序檢查，取第一個成立的值          | `ifs(prop("分數") >= 90, "A", prop("分數") >= 60, "B", "C")` |
| `and(a, b, …)`、`or(a, b, …)`          | 全部成立／任一成立                  | `and(prop("完成"), prop("數量") > 0)`                        |
| `not(a)`                               | 反過來                              | `not(prop("完成"))`                                          |
| `empty(值)`                            | 是否為空（空白、0、空清單、未勾選） | `empty(prop("備註"))`                                        |

不是 true/false 的值當條件時：空白、0、空文字、空清單算「不成立」，其他算「成立」。

## 數字

| 函式                                     | 說明                     | 例子 → 結果                 |
| ---------------------------------------- | ------------------------ | --------------------------- |
| `round(x, 小數位數)`                     | 四捨五入，位數預設 0     | `round(3.456, 2)` → 3.46    |
| `ceil(x)`、`floor(x)`                    | 無條件進位／捨去         | `ceil(2.1)` → 3             |
| `abs(x)`                                 | 絕對值                   | `abs(-5)` → 5               |
| `sqrt(x)`、`cbrt(x)`                     | 平方根、立方根           | `sqrt(16)` → 4              |
| `pow(x, y)`                              | 次方                     | `pow(2, 10)` → 1024         |
| `mod(x, y)`                              | 餘數                     | `mod(10, 3)` → 1            |
| `sum(…)`                                 | 加總，可放多個數字或清單 | `sum(1, 2, 3)` → 6          |
| `min(…)`、`max(…)`                       | 最小、最大               | `max(prop("A"), prop("B"))` |
| `mean(…)`、`median(…)`                   | 平均、中位數             | `mean([1, 2, 6])` → 3       |
| `sign(x)`                                | 正負號（1、0、-1）       | `sign(-3)` → -1             |
| `exp(x)`、`ln(x)`、`log10(x)`、`log2(x)` | 指數、對數               | `log10(1000)` → 3           |
| `pi`、`e`                                | 圓周率、自然常數         | `round(pi, 2)` → 3.14       |
| `toNumber(x)`                            | 文字轉數字，轉不了時為空 | `toNumber("42")` → 42       |

## 文字

| 函式                           | 說明                           | 例子 → 結果                                 |
| ------------------------------ | ------------------------------ | ------------------------------------------- |
| `concat(a, b, …)`              | 接起來                         | `concat(prop("名稱"), " - ", prop("狀態"))` |
| `format(x)`                    | 任何值轉成文字                 | `format(42) + "元"` → "42元"                |
| `length(文字)`                 | 字數                           | `length("你好")` → 2                        |
| `contains(文字, 片段)`         | 是否包含                       | `contains(prop("備註"), "急")`              |
| `lower`、`upper`、`trim`       | 轉小寫、大寫、去頭尾空白       | `upper("abc")` → "ABC"                      |
| `replace(文字, 規則, 換成)`    | 取代第一個（規則是正規表示式） | `replace("a-b-c", "-", "/")` → "a/b-c"      |
| `replaceAll(文字, 規則, 換成)` | 全部取代                       | `replaceAll("a-b-c", "-", "/")` → "a/b/c"   |
| `test(文字, 規則)`             | 是否符合正規表示式             | `test(prop("編號"), "^A\\d+")`              |
| `split(文字, 分隔)`            | 切成清單                       | `split("a,b", ",")` → ["a", "b"]            |
| `substring(文字, 開始, 結束)`  | 取一段（從 0 算）              | `substring("ABCDE", 1, 3)` → "BC"           |
| `repeat(文字, 次數)`           | 重複                           | `repeat("★", prop("星等"))`                 |

## 清單與關聯欄位

`prop("關聯欄位")` 是關聯到的列的清單。在 `map`、`filter` 等函式裡，
**`current`** 代表正在處理的那一項，**`index`** 是它的位置（從 0 算）；
`current.prop("欄位")` 讀取那一列的欄位。

| 函式                                    | 說明                                       | 例子                                                |
| --------------------------------------- | ------------------------------------------ | --------------------------------------------------- |
| `length(清單)`                          | 有幾項                                     | `prop("裝備").length()`                             |
| `map(清單, 運算)`                       | 每一項各算一次，得到新清單                 | `prop("裝備").map(current.prop("價格"))`            |
| `filter(清單, 條件)`                    | 只留下符合的                               | `prop("裝備").filter(current.prop("價格") > 100)`   |
| `find(清單, 條件)`                      | 第一個符合的項目                           | `prop("裝備").find(current.prop("類型") == "武器")` |
| `findIndex(清單, 條件)`                 | 第一個符合的位置，沒有時為 -1              |                                                     |
| `some(清單, 條件)`、`every(清單, 條件)` | 有任一符合／全部符合                       | `prop("任務").every(current.prop("完成"))`          |
| `sum`、`min`、`max`、`mean`、`median`   | 數字清單的統計                             | `prop("裝備").map(current.prop("價格")).sum()`      |
| `join(清單, 分隔)`                      | 接成文字                                   | `prop("裝備").map(current.prop("名稱")).join("、")` |
| `first`、`last`、`at(清單, 位置)`       | 第一項、最後一項、指定位置（負數從後面算） | `prop("裝備").first()`                              |
| `slice(清單, 開始, 結束)`               | 取一段                                     |                                                     |
| `sort`、`reverse`、`unique`、`flat`     | 排序、反轉、去重複、攤平                   | `prop("標籤").sort()`                               |
| `includes(清單, 值)`                    | 是否包含                                   | `prop("標籤").includes("重要")`                     |
| `count(清單)`                           | 不是空白的項目數                           |                                                     |
| `concat(清單1, 清單2)`                  | 合併清單                                   |                                                     |

常用的關聯彙總（類似 Notion 的 Rollup）：

```
prop("裝備").length()                                        關聯了幾筆
prop("裝備").map(current.prop("價格")).sum()                  價格加總
prop("裝備").filter(current.prop("價格") > 100).length()      價格超過 100 的筆數
prop("任務").filter(current.prop("完成")).length() / prop("任務").length()   完成比例
prop("裝備").map(current.prop("名稱")).join("、")             名稱串起來
```

## 日期

單位可以是 `"years"`、`"quarters"`、`"months"`、`"weeks"`、`"days"`、`"hours"`、`"minutes"`、`"seconds"`（單數也可以）。

| 函式                                      | 說明                                             | 例子                                         |
| ----------------------------------------- | ------------------------------------------------ | -------------------------------------------- |
| `now()`、`today()`                        | 現在時間、今天 0 點                              |                                              |
| `dateAdd(日期, 數量, 單位)`               | 加上一段時間                                     | `dateAdd(prop("開始"), 7, "days")`           |
| `dateSubtract(日期, 數量, 單位)`          | 減去一段時間                                     |                                              |
| `dateBetween(甲, 乙, 單位)`               | 甲減乙相差多少（取整數）                         | `dateBetween(prop("截止"), today(), "days")` |
| `formatDate(日期, 格式)`                  | 轉成文字，格式如 `"yyyy-MM-dd"`、`"MM/dd HH:mm"` | `formatDate(prop("截止"), "yyyy/MM/dd")`     |
| `year`、`month`、`date`、`hour`、`minute` | 年、月（1–12）、日、時、分                       | `month(prop("生日"))`                        |
| `day(日期)`                               | 星期幾（0 是星期日）                             |                                              |
| `timestamp(日期)`、`fromTimestamp(毫秒)`  | 日期和毫秒數互轉                                 |                                              |
| `parseDate(文字)`                         | 文字轉日期                                       | `parseDate("2026-12-31")`                    |

例子：`if(dateBetween(prop("截止"), today(), "days") < 0, "已逾期", "還有 " + format(dateBetween(prop("截止"), today(), "days")) + " 天")`

## 暫存變數：`let`、`lets`

公式很長、同一段算很多次時，可以先取名字：

```
let(小計, prop("價格") * prop("數量"), if(小計 > 1000, 小計 * 0.9, 小計))
lets(單價, prop("價格"), 數量, prop("數量"), 單價 * 數量)
```

## 錯誤訊息

格子裡出現紅色 ⚠ 時，把滑鼠移上去可以看完整訊息。

| 訊息                               | 原因                                                  |
| ---------------------------------- | ----------------------------------------------------- |
| `No property named "…"`            | 欄位名稱打錯，或欄位已改名                            |
| `Unknown name "…"`                 | 文字少了引號，或 `prop` 少了引號：要寫 `prop("價格")` |
| `Unknown function "…"`             | 函式名稱打錯（大小寫要一樣，例如 `dateBetween`）      |
| `Expected ")" …`                   | 括號沒有成對                                          |
| `… expects a number, got text`     | 用文字做數學運算，可先用 `toNumber()`                 |
| `The formula uses itself`          | 公式直接或間接讀到自己                                |
| `Not a number (division by zero?)` | 除以 0 之類的結果                                     |

## 和 Notion 的差異

- 支援的是常用函式（上面列出的），不是 Notion 的全部函式。
- 公式結果不能直接編輯；把欄位改成其他類型時，算出來的值不會保留。
- 只有網頁版（affine.nineday.com.tw）認得公式欄位，官方桌面版和手機 App 不認得。
